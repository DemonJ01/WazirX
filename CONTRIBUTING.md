# Contributing to WazirX

This repository currently provides a Next.js starter—not a working trading system.

1. Create a feature branch.
2. Set up Node.js and install dependencies as documented in the README.
3. Run linting, TypeScript checks and a production build.
4. Add regression tests for real features rather than inventing passing results.
5. Open a reviewable pull request explaining changes and risks.

Never commit wallet private keys, API tokens, exchange credentials, user information, or seed phrases. Changes concerning financial transactions require a separate architecture, legal and security review.
