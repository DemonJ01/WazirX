# Security policy — WazirX

**No production exchange security guarantees exist.** The connected repository has a Next.js starter, not a complete exchange.

Do not enter, transmit or commit crypto wallet seed phrases, private keys, exchange credentials, personal information or payment data.

Future implementations must address user authentication, authorization, account protection, cryptographic key management, secure transaction processing, API abuse prevention, transaction audit trails, dependency integrity and applicable legal/compliance requirements.

Report potential vulnerabilities privately to a verified maintainer or through GitHub private reporting if enabled. Do not post exploit details or credentials in public issues. No formal support SLA is established.
